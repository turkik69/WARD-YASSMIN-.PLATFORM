الاتصال بالذكاء الاصطناعي

عند فتح هذه المنصة خارج تطبيق Claude (مثل متصفح Safari مباشرة)، تحتاج المنصة مفتاح Anthropic API حتى تعمل الدروس والاختبارات والمعلّم الذكي. المفتاح يُحفظ على هذا الجهاز فقط، ولا يُرسل لأي مكان سوى Anthropic مباشرة.

يمكنك إنشاء مفتاح من console.anthropic.com (حساب Anthropic API منفصل عن اشتراك Claude، ويُفوتَر حسب الاستخدام). داخل تطبيق Claude نفسه لا حاجة لأي مفتاح — المنصة تعمل تلقائياً.
